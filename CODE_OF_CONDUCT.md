# Code of Conduct

This project follows the Contributor Covenant, version 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful, welcoming and constructive; harassment and discrimination are not tolerated.
Report concerns to the maintainers by opening a confidential report through the repository's
security/contact channel once it is published. Maintainers will review and respond to every report.
