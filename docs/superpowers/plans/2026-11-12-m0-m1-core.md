# OpenPolitics M0 + M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the repository foundation (M0) and a deterministic, data-driven simulation core with headless runner and starter pack (M1).

**Architecture:** `OpenPolitics.Core` (no Godot types) loads YAML data packs, evaluates an influence graph of rate-of-change edges, steps a small macro economy behind `IEconomyModel`, and exposes a narrow `Game` API. `OpenPolitics.Cli` hosts `validate`, `run`, `batch`. All content lives in `data/`.

**Tech Stack:** .NET SDK 10.0.404 (`net10.0`), C#, xUnit, YamlDotNet, GitHub Actions. No other runtime dependencies in Core except YamlDotNet.

**Spec:** `docs/specs/2026-11-12-simulation-model-design.md` (M1) and `docs/specs/2026-11-12-m0-foundation-design.md` (M0); decisions in `docs/decisions/0001-initial-decisions.md`. Read all three first.

## Global Constraints

- Shell setup for every command: `export PATH="$HOME/.dotnet:$PATH"`; run from repo root.
- Target framework `net10.0`; `Nullable` enabled; warnings are errors (`Directory.Build.props`).
- `core/` references no Godot types and does no I/O except through `IPackSource`.
- Determinism: PCG32 PRNG only (no `System.Random`); no `DateTime`/wall-clock; never iterate `Dictionary`/`HashSet` where order affects results – use ordinal-sorted lists. Transcendental math goes through `DetMath` (basic IEEE ops only) so results are identical across platforms.
- Economic/social values are in real units with **no ceiling or fixed scale**; only voter satisfaction is bounded to [-1, 1].
- Edges change rates, never target levels. Turn = one quarter (`dt = 0.25` year), start 2015, both from the scenario.
- Ids are namespaced strings `pack:name` (`^[a-z0-9_]+:[a-z0-9_]+$`). Player-visible text only via localization keys (cs, en).
- Packs contain data only; `illustrative: true` in the base manifest. Fictional parties/politicians only (none in M1).
- Code MIT, `data/` CC BY-SA 4.0. Docs, identifiers and commits in English. Small commits; every commit ends with the attribution line from the session's system-reminder.
- TDD: every code task writes the failing test first and runs it to see it fail.

## Review Focus

1. **Malformed pack files** (BOM, CRLF, tabs, empty file, unknown field): a `Diagnostic` with file and line, never an exception. Pinned in Task 4.
2. **Zero or negative inputs to edge functions** (`scale = 0`, negative base in `power`, `ref` equal to value): no NaN/Inf, defined result. Pinned in Task 7.
3. **Loading a save against different pack contents**: explicit error naming the pack whose hash differs, not silent divergence. Pinned in Task 11.
4. **Player action with unknown policy id or value outside `[min, max]`**: rejected `ActionResult`, state unchanged. Pinned in Task 11.
5. **Seeds `0` and `ulong.MaxValue`, 10 000 consecutive `EndTurn()` calls**: deterministic, no exception, no NaN. Pinned in Task 14.
